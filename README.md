# Kakutabi releases

Kakutabi Writer (students) and Kakutabi Studio (teachers and TAs), Windows x64.

Download installers from [Releases](https://github.com/noriki-mochizuki/kakutabi-releases/releases/latest).

After the initial installation, use the update icon inside the app to update and restart. Save TA feedback before updating. Updates verify a product-specific signature before installation. Windows publisher signing is not provided; your institution's Windows policies still apply.

This repository contains distribution notices only. Application source code, student reports, keys, operation logs, private test builds, and sample data are not published here. GitHub's automatic source archives contain only this repository's distribution notices.
